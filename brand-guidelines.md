# Day Book — Brand Guidelines

## 1. Brand Overview

**Brand Name:** Day Book

**Page Title:** DayBook - What's my birthday?

**Description:**  
A stylish, lightweight birthday tracker for keeping track of family and friends' birthdays — so you never forget one again. 🎉🎂

### Brand Personality

Day Book should feel:

- Warm
- Friendly
- Playful
- Modern
- Personal
- Celebratory
- Clean

The design should feel polished and intentional without becoming overly corporate or generic.

---

# 2. Typography

## Font Family

Use **Satoshi** as the primary font family.

Satoshi should be used consistently throughout the application and should support all available:

- Font weights
- Font styles

### Typography Direction

Typography should feel:

- Modern
- Clean
- Friendly
- Highly readable

Use font weight and size to establish a clear visual hierarchy rather than relying heavily on decorative elements.

Headings should feel prominent and expressive, while supporting text should remain clean and easy to read.

---

# 3. Color & Theme

Day Book should support both **Light Mode** and **Dark Mode**.

Both themes should feel like part of the same brand rather than looking like completely different designs.

## Light Theme

The light theme should feel:

- Bright
- Warm
- Soft
- Clean
- Welcoming

Avoid using a completely plain white background.

## Dark Theme

The dark theme should feel:

- Comfortable
- Modern
- Elegant
- Soft
- Easy on the eyes

Avoid using pure black as the primary background. Prefer a slightly softened dark tone that allows the UI elements and celebratory elements to stand out.

## Theme Consistency

Both themes should maintain:

- Consistent typography
- Consistent spacing
- Consistent component shapes
- Consistent visual hierarchy
- Consistent brand personality

Colors should adapt appropriately between themes while preserving sufficient contrast and accessibility.

---

# 4. Background & Visual Style

The application should **not use a completely plain background**.

The background should have a subtle visual treatment that gives the page more personality while keeping the content as the primary focus.

### Background Direction

Use a combination of:

- Subtle gradients
- Soft geometric shapes
- Very light decorative elements
- Gentle visual depth

The geometric shapes should be subtle and should not compete with the content.

### Guidelines

- Keep background decorations low-contrast.
- Avoid excessive patterns.
- Avoid visual noise.
- Do not place decorative elements where they interfere with text or interactive elements.
- Background decorations should work in both light and dark themes.
- The background should enhance the celebratory feeling without looking like a party-themed template.

The overall goal is:

> **Subtle visual personality rather than a distracting decorative background.**

---

# 5. Celebratory Visual Language

Day Book is a birthday-focused application, so the design should have a subtle sense of celebration.

Use celebratory elements thoughtfully, such as:

- Confetti
- Soft gradients
- Rounded cards
- Subtle animations
- Playful geometric shapes
- Friendly typography

Celebratory elements should feel **modern and tasteful**, not overly childish or visually overwhelming.

Animations should enhance the experience rather than distract from the birthday information.

---

# 6. Components & Visual Direction

UI components should generally follow a:

- Clean
- Modern
- Rounded
- Friendly
- Lightweight

visual style.

Cards, dialogs, buttons, and interactive elements should feel cohesive across the application.

Avoid overly sharp, rigid, or corporate-looking components unless required for usability or accessibility.

Interactive elements should provide clear visual feedback for:

- Hover
- Focus
- Active
- Disabled
- Selected states

---

# 7. Spacing & Layout

The layout should feel spacious and breathable.

Prioritize:

- Clear section separation
- Consistent spacing
- Comfortable content density
- Strong visual hierarchy
- Good alignment

Avoid packing too much information into a single area.

The birthday information should always remain the primary focus of the page.

---

# 8. Imagery & Avatars

Birthday celebrants should be represented using friendly and visually interesting avatars.

For the initial implementation, use **Avvvatars** with the **shapes variant**.

Avvvatars:

- https://avvvatars.com
- https://github.com/nusu/avvvatars

Avatars should:

- Be visually consistent throughout the application.
- Scale appropriately across responsive layouts.
- Remain recognizable at smaller sizes.
- Have appropriate spacing from names and other information.

The avatar system should be visually compatible with both light and dark themes.

---

# 9. Responsive Visual Design

Day Book should provide a consistent visual experience across:

- Desktop
- Tablet
- Mobile

The visual identity should remain consistent regardless of screen size.

On smaller screens:

- Prioritize the birthday information.
- Reduce unnecessary decorative elements when space is limited.
- Maintain comfortable spacing.
- Ensure interactive elements remain easy to tap.
- Avoid horizontal scrolling.
- Ensure dialogs and cards fit naturally within the viewport.

---

# 10. Footer & Attribution

The application should include a small footer area positioned at the **bottom-left corner** of the page.

The footer should contain:

### GitHub Repository

Display a **GitHub icon** that links to the project's GitHub repository.

The repository URL should be configurable and should not be hard-coded into unrelated components.

### Creator Attribution

Display:

> Made by Nomer with <3

The attribution should link to:

https://www.nmrisrl.dev/

The footer should remain subtle and should not compete with the main birthday content.

### Footer Design

The footer should:

- Be visually minimal.
- Use the secondary/muted text styling.
- Remain readable in both light and dark themes.
- Provide appropriate hover and focus states for links.
- Remain accessible on mobile devices.

---

# 11. Overall Design Direction

The final Day Book experience should feel like a **personal, stylish birthday dashboard** rather than a generic calendar application.

The visual hierarchy should generally be:

1. **Current birthday celebrant(s)**
2. **Upcoming birthdays**
3. **All birthdays by month**
4. **Supporting navigation and attribution**

The design should balance:

**Celebration + Simplicity + Personality + Usability**

Avoid:

- Generic dashboard aesthetics
- Plain white/black backgrounds
- Excessive gradients
- Excessive animations
- Overly colorful interfaces
- Cluttered layouts
- Childish birthday graphics
- Unnecessary decorative elements

The goal is a **modern, warm, and memorable birthday experience** that feels distinctly like Day Book.
